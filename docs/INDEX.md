Login\n```objc\n[PPBiometric.shared authenticateFrom:viewController\n                               reason:@\"Authenticate to login\"\n                           completion:^(NSString *email, NSString *password, NSError *error) {\n    if (!error) {\n        [self signInWithEmail:email password:password];\n    }\n}];\n```\n\n### Unlock App\n```objc\n[PPBiometric.shared authenticateUserPresenceWithReason:@\"Unlock Pure Pets Admin\"\n                                             completion:^(BOOL success, NSError *error) {\n    if (success) {\n        [self dismissLockOverlay];\n    }\n}];\n```\n\n### Check Availability\n```objc\nif ([PPBiometric.shared isBiometricAvailable]) {\n    LABiometryType type = [PPBiometric.shared biometryType];\n    // LABiometryTypeFaceID, LABiometryTypeTouchID, or LABiometryTypeNone\n}\n```\n\n## 🔒 Security Features\n\n✅ **Keychain Storage**\n- Email and password encrypted at rest\n- Access protected by Face Invalidated if biometric enrollment changes\n- No passcode-only access\n\n✅ **Credential Management**\n- Credentials only saved after successful auth\n- Automatically disabled on failed auth\n-
